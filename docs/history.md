# Журнал проекта

## 1. Идея (октябрь–ноябрь 2026)

- **Было:** 7 механических терморегуляторов Valtec VT.AC602 с датчиками в полу, NC-сервоприводы 220 В, электрокотёл Protherm 9 кВт, двухтарифный счётчик.
- **Рассматривали** Wi-Fi терморегуляторы Beok (7 шт.). Выбрали другой путь: **одна плата на все зоны + настенный экран**. Так дешевле, без облака, с прицелом на домашний сервер и Алису.
- **Решили** подключить Нептун к той же системе, но оставить его самостоятельным устройством защиты.

## 2. Плата реле

- Заказали ESP32-плату на 8 реле. Пришла **ESP8266 (ESP-07)**, по продавцу открыт спор.
- Прошивка не шла: провод GND был на IO2, потом плохой контакт. Перепаяли, заработало.
- Tasmota не загружалась, потому что GPIO0 занят реле. Перешли на **ESPHome**.
- Все 8 реле проверены.

## 3. Датчики пола

- У ESP8266 только один аналоговый вход, поэтому поставили **2 × ADS1115** (адреса 0x48 и 0x49).
- I2C пришлось посадить на GPIO2 и GPIO3 (RXD), из-за этого лог по UART выключен.
- **Ошибка: показывало 170°C.** Делитель был собран неправильно. Правильно так: резистор от +3,3 В к входу, датчик от входа к GND. После этого тест показал 24,2°.
- **Ошибка: при отключённом датчике держалось старое значение.** Сделали так: обрыв → NaN → зона принудительно закрывается, а в статусе пишется «ОБРЫВ: …».
- **Ошибка: вход без резистора показывал ложные 22,4°** и включал котёл. Вывод: резисторы подтяжки нужны постоянно.

## 4. Котёл

- На плате котла MEK21_3 есть колодка `+BUS− | RT24V | LIMITER`. С RT24V сняли перемычку и подключили реле 8 как сухой контакт. Проверено: котёл включается и выключается.
- Логика: зона открылась → через 3 минуты включается котёл. Все зоны закрыты → котёл выключается.

## 5. Веб-страница платы

- Белая страница: включили `local: true`, а потом убрали группы (`sorting_groups`). Для ESP8266 страница всё равно тяжеловата, поэтому основное управление — экран.
- Одинаковые русские имена сущностей давали повторяющиеся ID. Помогли цифры в именах («Пол 4 Спальня», «1 Балкон»).
- После обновления по воздуху плата пропала из сети. Перепрошили кабелем.

## 6. Экран

- Sunton ESP32-8048S070C. На Windows ESP-IDF не собирался из-за русского имени пользователя, сделали обход в `esp.bat`.
- v1: плитки комнат с кнопками −/+ и связь с платой по UDP. Задержка 3–5 с, это приемлемо.
- v2 по пожеланиям:
  - только режимы «Дома» / «Ушёл»;
  - ночной режим перенесён в настройки;
  - без кнопки «Boost»;
  - спокойные цвета, без оранжевого и красного;
  - без расчётов по тарифам, «здесь чисто управление тёплым полом»;
  - в режиме «Ушёл» закрывается вода.
- **Мерцание:**
  - экран перерисовывался без изменений → теперь обновляет только то, что поменялось;
  - добавлен кэш PSRAM и ШИМ подсветки 20 кГц;
  - выяснилось, что экран не подключился к Wi-Fi: в файле остался пароль-заглушка → пароли вынесены в `secrets.yaml`.
  - настройки кэша PSRAM мешали работе Wi-Fi → откатили;
  - подсветку перевели с ШИМ на простое вкл/выкл → мерцание почти пропало;
  - от USB ноутбука мерцает сильнее, от зарядки 5 В заметно меньше;
  - осталось лёгкое мерцание, терпимо. Если понадобится, можно поднять частоту обновления дисплея (сейчас около 25 Гц).
- Журнал экрана выведен в UART0, теперь он виден по USB-кабелю.
- Сборка сломалась на испорченных файлах прошлой сборки → `esp.bat ekran.yaml clean` (полная пересборка).
- **Ошибки сборки:**
  - `lv_color_to32` нет в этой версии LVGL;
  - `UnicodeDecodeError` в CMakeCache (русский путь);
  - `timezone: Europe/Moscow` не находится на Windows → `MSK-3`;
  - имя `clock` зарезервировано → `upd_clock`.
- Добавлена дата рядом с часами.

## 7. GitHub

- Создан репозиторий `home_smart`. `esp.bat` сам делает `git pull` перед прошивкой.
- Сеть Wi-Fi и пароли вынесены в `secrets.yaml`, в репозитории их нет.
