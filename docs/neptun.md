# Нептун: план подключения

**Цель:** закрывать и открывать воду с экрана и голосом. В режиме «Ушёл» вода закрывается автоматически. Нептун остаётся главным устройством защиты: если наша электроника выключится, он продолжает работать сам.

## Что есть

- Нептун Base RS, плата Atlantic004-V2, краны Bugatti Pro 220 В, 2 проводных датчика.
- На плате есть клеммы RS-485: **D+ / D− / GNDRS**.
- Экран уже отправляет команду `water_cmd`: 1 = закрыть, 0 = открыть.

## Основной вариант: RS-485 (Modbus)

```
Плата реле (разъём прошивки 5V/GND) ──► ESP32-C3 SuperMini
ESP32-C3 GPIO21 (TX) ──► XY-017 RXD      XY-017 A+ ──► Нептун D+
ESP32-C3 GPIO20 (RX) ◄── XY-017 TXD      XY-017 B− ──► Нептун D−
ESP32-C3 3V3 / GND   ──► XY-017 VCC/GND  XY-017 GND ─► Нептун GNDRS
```
HLK-5M05 не нужен: 5 В берём с платы реле (меньше узлов на 220 В в коробке).
Прошивка: `neptun.yaml` (тестовая).

## Порядок, чтобы не лезть в коробку после монтажа
1. ESP32-C3 + XY-017 спаять на столе, первая прошивка `neptun.yaml` — по USB-C.
2. Временно подключить к Нептуну, открыть в браузере страницу `neptun` (IP из роутера):
   - видно ли ячейки HR0/HR1 (ответил ли Нептун вообще);
   - работает ли переключатель «Краны» (закрыть/открыть).
3. Поставить в коробку, к Нептуну протянуть сетевой кабель (витая пара): одна пара — A/B, один провод — GND, остальные — запас (на случай реле на кнопку).
4. Закрыть коробку. Все дальнейшие обновления — по Wi-Fi.

Карта регистров — официальная «ModBus_Карта памяти регистров Base» (документы к комплекту Neptun Base SE RS на neptunsale.ru): **адрес 1, 9600 8N1, только holding-регистры** (чтение 0x03, запись 0x10). HR0 = 0x4E42 (тип), HR5 адрес, HR6 скорость (0=1200 … 3=9600 … 7=115200), HR10 управление (бит0 звук, бит1 краны 1=открыть/0=закрыть), HR11 статус (бит0 протечка, бит1 краны закрыты, бит2 сервис). Прежняя карта (coil/input, от системы со страницы Алисы) к Base RS не подходит.

### Если Нептун не отвечает
Параметры по умолчанию уже перебирает `neptun_scan.yaml`, значит причина почти наверняка в железе:
1. Напряжения (Нептун включён, XY-017 отключён от линии): D+ к GNDRS, D− к GNDRS, D+ к D−. В покое D+ должен быть выше D− хотя бы на 0,2 В.
2. XY-017 питать от 3V3 (вход ESP32-C3 не терпит 5 В). Общий GND ESP ↔ XY-017 ↔ GNDRS.
3. TX/RX: поменять `tx_pin`/`rx_pin` в начале yaml (перепаивать не нужно).
4. Журнал по USB: в `neptun.yaml` включён `uart: debug` — видно `>>>` (отправили) и `<<<` (пришло).
5. Независимая проверка — USB-RS485 свисток и программа Modbus Poll / QModMaster на ноутбуке: адрес 1, 9600 8N1, функция 03, регистр 0, ждём 20034.
Безопасность: автоматическое открытие воды по команде экрана не включаем, пока не будет проверки «не открывать при протечке».

- ESP32-C3 принимает `water_cmd` от экрана и пишет команду в регистр Нептуна.
- Он же читает состояние кранов и датчиков и отправляет его на экран.
- Карта регистров Modbus запрошена в поддержке Нептуна, ответа пока нет.

## Запасной вариант: реле на кнопку

Если по RS-485 не получится, модуль на 2 реле подключается параллельно кнопкам открыть/закрыть и «нажимает» их.

## Беспроводные датчики

2 датчика протечки Tuya SECUGARD (Wi-Fi). Их план интеграции появится после покупки.

## Связь с экраном (UDP, 26.11)
- Экран шлёт `water_req = номер_команды * 2 + (1 закрыть / 0 открыть)`. Нептун выполняет команду только при смене номера (нажатие «Закр.»/«Откр.», «Дома»/«Ушёл» на экране, «Ушёл» из HA). Перезагрузка экрана или Нептуна воду не открывает.
- «Открыть» Нептун выполняет только при известном статусе и без протечки. Из Home Assistant открыть воду нельзя.
- Нептун шлёт экрану `np_link`, `np_leak`, `np_closed`; плитка «Вода»: открыта / закрыта / ПРОТЕЧКА! (красная) / нет связи.
- UDP в домашней сети без шифрования, как у платы пола.
- Ход кранов (паспорт 120 с): Нептун меняет флаг «закрыты» только в конце хода, поэтому после команды (смена бита 1 в HR10) до 150 с показываем «закрывается.../открывается...» (np_closing/np_opening).

## Беспроводные датчики протечки (Tuya, Wi-Fi) — 26.11
- Датчики подключаются в приложении Smart Life (Tuya), в Home Assistant — интеграция **Tuya** (вход по QR-коду из приложения).
- Экран отдаёт в HA кнопку «Закрыть воду (close)» и текст «Вода (water)». Автоматизация HA: датчик протечки «влажно» → нажать кнопку экрана. Открыть воду из HA нельзя.
- Ограничение: Tuya работает через облако — без интернета автоматизация не сработает. Проводные датчики Нептуна работают всегда.
