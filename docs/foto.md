# Фотогалерея на экране

Когда экран не трогают «Гасить экран через» N минут, вместо отключения подсветки он
показывает фото по кругу (в углу — часы). Касание в любом месте возвращает главный экран.

- **Ночью** (если включён «Ночной режим каждый день», в часы ночи) и в режиме **«Ушёл»**
  экран, как раньше, просто гаснет. Если ночь наступила во время показа — гаснет сам.
- Настройки → «Фото при простое, смена»: Выкл → 10 с → 30 с → 1 мин → 5 мин.
  «Выкл» — старое поведение (экран гаснет).
- Если фото нет или Home Assistant выключен — экран просто гаснет.

## Почему не карта памяти
Слот microSD на Sunton ESP32-8048S070C есть (SPI: CS GPIO10, MOSI GPIO11, CLK GPIO12,
MISO GPIO13), но в ESPHome нет штатного компонента для чтения файлов с SD и показа JPEG
из файла. Поэтому экран скачивает фото по сети с Home Assistant (компонент `online_image`; HA слушает порт 80)
— менять фото удобнее, экран снимать со стены не нужно.

## Как положить фото (через браузер, без компьютера)
Фото загружаются в «Медиа» Home Assistant с телефона или ПК, сервер сам подгоняет их
под 800×480 (раз в 5 минут) и выкладывает для экрана. Любые фото с телефона: JPEG, PNG,
в том числе «прогрессивные» и огромные. HEIC с айфона — нет: в настройках камеры
выбрать «Наиболее совместимый» или отправлять как JPEG.

**Один раз настроить** (дополнение File editor: Настройки → Дополнения → File editor):
1. Создать файл `/config/ekran_foto.py`, вставить содержимое `ha/ekran_foto.py`.
2. В конец `/config/configuration.yaml` вставить содержимое `ha/ekran_foto.yaml`.
3. Настройки → Система → ⋮ → Перезапуск Home Assistant. При запуске появятся папки
   `/media/ekran` и `/config/www/ekran`.

**Добавлять фото:** Медиа → Мои медиа → папка **ekran** → «Загрузить медиа».
Через 5 минут (или сразу: Настройки → Автоматизации → «Экран: обновить фото» → Выполнить)
фото появятся на экране. Удалили в «Медиа» — пропадёт и с экрана. Порядок — по имени файла.

Проверка: `http://192.168.1.110/local/ekran/foto1.jpg`. Журнал обработки —
Настройки → Система → Журналы (ошибки `shell_command`).

Запасной путь — подготовить на компьютере `tools/foto.py` и положить готовые
`foto1.jpg`, ... прямо в `/config/www/ekran/`. Пока папка `ekran` в «Медиа» пуста,
сервер их не трогает; как только там появится хоть одно фото — заменит своими.

Экран идёт foto1, foto2, ... и на первом отсутствующем номере возвращается к foto1.
Новые фото подхватываются без перепрошивки.

Папка `/local/` отдаётся без пароля, но HA в интернет не открыт — фото видны только в
домашней сети. Ничего личного, что нельзя показывать гостям, туда не класть.

## Если что-то не так
- Цвета «перепутаны» (синие лица) — в `gen_ekran.py` у `online_image` добавить
  `byte_order: BIG_ENDIAN`, перегенерировать и прошить.
- Фото не появляется — смотреть логи экрана в ESPHome Builder (ошибки `online_image`).
