# Фотогалерея на экране

Когда экран не трогают «Гасить экран через» N минут, вместо отключения подсветки он
показывает фото по кругу (в углу — часы). Касание в любом месте возвращает главный экран.

- **Ночью** (если включён «Ночной режим каждый день», в часы ночи) и в режиме **«Ушёл»**
  экран, как раньше, просто гаснет. Если ночь наступила во время показа — гаснет сам.
- Настройки → «Фото при простое, смена»: Выкл → 10 с → 30 с → 1 мин → 5 мин.
  «Выкл» — старое поведение (экран гаснет).
- Если фото нет или Home Assistant выключен — экран просто гаснет.

## Почему не карта памяти
Слот microSD на Sunton ESP32-8048S070C есть (SPI: CS GPIO10, MOSI GPIO11, CLK GPIO12,
MISO GPIO13), но в ESPHome нет штатного компонента для чтения файлов с SD и показа JPEG
из файла. Поэтому экран скачивает фото по сети с Home Assistant (компонент `online_image`)
— менять фото удобнее, экран снимать со стены не нужно.

## Как положить фото
1. Подготовить: `pip install pillow`, затем
   `python tools/foto.py <папка с фото> <папка вывода>` — получится `foto1.jpg`, `foto2.jpg`, ...
   (800×480, обычный JPEG; progressive JPEG экран не читает). `--pad` — вписать целиком
   с чёрными полями вместо обрезки.
2. Скопировать файлы на Home Assistant в `/config/www/ekran/` — через дополнение
   **File editor** (Настройки → Дополнения, кнопка загрузки файла) или **Samba share**.
   Если папки `www` раньше не было — после создания один раз перезапустить Home Assistant.
3. Проверить в браузере: `http://192.168.1.110:8123/local/ekran/foto1.jpg`.

Номера должны идти подряд без пропусков: экран идёт foto1, foto2, ... и на первом
отсутствующем номере возвращается к foto1. Новые фото подхватываются без перепрошивки.

Папка `/local/` отдаётся без пароля, но HA в интернет не открыт — фото видны только в
домашней сети. Ничего личного, что нельзя показывать гостям, туда не класть.

## Если что-то не так
- Цвета «перепутаны» (синие лица) — в `gen_ekran.py` у `online_image` добавить
  `byte_order: BIG_ENDIAN`, перегенерировать и прошить.
- Фото не появляется — смотреть логи экрана в ESPHome Builder (ошибки `online_image`).
